# ECE1895_proj2
https://www.youtube.com/watch?v=CHNRelYjLn8<br>
a soccer-themed multiplayer “Bop It” game. Two players will compete to complete the specific instruction for the round using a motion-controlled input device. The device will indicate which player completed the specific action first, and they will be awarded a point. The game will end when one of the players reaches a specific number of points. This scoring will encourage speed and accuracy when responding to commands. The input devices for our game will be two IMU’s or inertial measurement units. This device combines an accelerometer with a gyroscope to capture precise motion and orientation data of the device. The data can be used to determine how the player has moved the device and can be matched to a set of preprogramed movements. Our design will have a main microcontroller that takes the inputs from the two sensors and processes the data. The scores will be shown on seven-segment displays with counter IC’s to easily increment the score with the microcontroller. Instructions will be played directly from the microcontroller and will call out specific soccer-themed actions through a speaker. After the instruction is called out, the microcontroller will monitor the two inputs to make sure that they match the required move and determine who completes the command first. The game will have a reset switch which will allow the players to reset the game and start up a new round.
